# V294 source census scope

The Oct 10 2026 corpus contains exactly 1,295 logical SpecRGB names, not a mapping from names to material slots. A slot requires exact FLVER SHA + original g_Specular texture path + material MTD. Unknown rows must be marked unresolved; do not infer owner from FNV or basename similarity. This census is diagnostic and does not waive receiver identity, shader consumer or native t1 resource checks.
