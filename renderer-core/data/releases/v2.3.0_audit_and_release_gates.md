## Release instrumentation cut (post V359 source contracts)

1. Compile out `DSRRL_V352_LONG_SOAK_PRESENT`,
   `DSRRL_V353_CPU_MODULE_PROFILER`, `DSRRL_V296_ROOTCAUSE_TELEMETRY`.
2. Default hot/effect profiling OFF, including environment opt-in for this
   release. QPC diagnostic-mode file reads and unload report suppressed
   while Scope Shell RAII stays in its V350 shape.
3. Remove info-level observation callsites in materialized sources; retain
   warning/error fail-open diagnostics and version/GPU-resident startup markers.
4. Disable integrated `log_state`, `log_effect_matrix` and read-only
   PointLight RT census function. The latter performs GetResource/viewport
   reads solely to report dimensions; no source/operator authorization.
5. Retain GI binder names, SHA/resource/view witnesses, two independent
   per-map attestation and conflict poisoning from V359, plus MTD/FLVER
   material authority. No operator equations, parameters or textures modified.
6. Do **not** automatically remove all fields named `telemetry`: several
   error/restore flags are safety decisions consumed by unload and fail-open.

## Known release risks

- Suppressing diagnostic sites can change compiler layout; V350 handoff
  explicitly warned that code shape correlates with hitch behavior, so
  repeat owner A/B after every binary rebuild. No unsupported performance claim.
- Widespread info logs may be semantically inert but were present on render-hot
  paths. Only observed info calls are removed; warnings/errors remain.
- V359 unknown BC6H probes are not proven GI_EnvSpc matches; no unconditional
  alias permission and no new donor whitelist.
- `DarkSoulsRemastered.exe` is never modified on disk.

Final promotion must cite GitHub artifact SHA, reproducible commit, Windows
native gate and owner runtime. No new tag should imply an untested production PASS.
